ZOOD PDF (زود PDF) — offline web app
=====================================

Windows: double-click "Start on Windows.cmd".
macOS / Linux: run ./start.sh in a terminal.

Both start a small local server (serve.mjs, no dependencies) on http://127.0.0.1:8787
(the next free port if that one is taken) and open your browser. Nothing is sent over the
network; the server only answers this computer. Close the window / press Ctrl+C to stop.

Requirement: Node.js 22 or newer (https://nodejs.org).

ويندوز: انقر نقرًا مزدوجًا على "Start on Windows.cmd".
ماك ولينكس: شغّل ‎./start.sh‎ من الطرفية.

يعمل خادم محلي صغير على ‎http://127.0.0.1:8787‎ ويفتح المتصفح. لا يُرسَل أي شيء عبر الشبكة،
والخادم لا يجيب إلا هذا الجهاز. المتطلب: Node.js ‏22 أو أحدث.
