# Feature matrix (Acrobat Pro parity map)

Status legend: ✅ done · 🟡 partial · ⬜ planned · ❌ out of scope. Targets: D = desktop, X = extension, W = web, M = mobile (Phase 9).

| Area | Feature | Tier | D | X | W | Status / notes |
|---|---|---|---|---|---|---|
| View | Open, zoom, fit modes, continuous scroll, thumbnails | MVP | ✅ | ✅ | ✅ | EmbedPDF (PDFium in WebAssembly) in all three hosts (ADR-0007); Warraq's own engine in Edit text. Menus, shortcuts, Go to page and the status bar act on the view on screen. On desktop the file comes in through the native open panel, an OS drop or a path on the command line, and goes out through the native save panel — a webview ignores the browser equivalents. The extension is proven by a test that loads it into Chrome |
| View | Bookmarks, attachments, layers panes | MVP | ✅ | ✅ | ✅ | Warraq's navigation pane, in both views (beside EmbedPDF's page view and beside the thumbnails in Edit text), opened from View → Bookmarks / Attachments / Layers, read by Warraq's core. Bookmarks: the outline with its levels, open/closed as the file says, a click goes to the page. Attachments: the document's and those on pages, with name, size, description; saved as an opaque file through the save panel (never opened or run), added (any file, with a description) and removed, as updates of the file. Layers: the order tree with groups, locked layers, print/export states shown; showing or hiding one changes only a copy the view draws until *Save layer visibility with the file* (e2e: the saved file is byte-identical until then). Layers are switched in the reading view; in Edit text the list is shown but not switched. EmbedPDF's own sidebar still has its outline and comments |
| View | Text selection and copy in logical order | MVP | 🟡 | 🟡 | 🟡 | reconstruction engine done; selection overlay in UI |
| View | Arabic-aware search | MVP | 🟡 | 🟡 | 🟡 | Warraq's engine (tashkeel-insensitive, alef/taa/yaa/digits unified) drives the find bar in Edit text and Redact's find and redact; EmbedPDF's search panel, in the main view, is PDFium's plain search |
| Comment | Highlight, underline, strikeout, sticky notes, drawing, shapes, stamps, text boxes, callouts, measurement | MVP | ✅ | ✅ | ✅ | EmbedPDF's annotation plugin, saved as standard PDF annotations (e2e: a drawing survives save and reopen). Measurement not yet. Arabic typed into a text box is drawn into the saved file by Warraq's shaping, the box grown to fit (e2e; checked in PDFium) |
| Organize | Insert, delete, rotate, reorder, extract, split, merge, crop | MVP | ✅ | ✅ | ✅ | Warraq's core (ADR-0008): rotate, reorder (drag or buttons), delete, insert a blank page or every page of another PDF (with its password, if it has one), extract as a new file and split into files (every so many pages or at the selected pages, one zip) and crop (margins as the page is shown, or the white trimmed away) work, with undo, as incremental updates (e2e: moved, turned, deleted pages keep their text through save and reopen). Combine files merges several (e2e: order kept, page by page by their text; a protected input opened with its password), keeping every form field |
| Compress | Image downsampling, object streams, font subsetting, presets | MVP | ✅ | ✅ | ✅ | Warraq's core, pure Rust in every host: unused objects dropped, duplicate streams shared, best Flate, object and xref streams; optional downsampling of oversized 8-bit grey/RGB images to 150 or 96 dpi JPEG (e2e: a 300 dpi scan more than halved; every page's text kept, checked on a 95-page Word export). Refuses protected and signed files. Font re-subsetting not yet |
| Fill & Sign | AcroForm fill, draw/type/image signature, initials, dates | MVP | ✅ | ✅ | ✅ | EmbedPDF's form and signature plugins (e2e: a typed value survives save and reopen). Arabic values are drawn into the saved file by Warraq's shaping, where PDFium wrote an empty appearance (e2e; checked in PDFium). On desktop the signature image is chosen in the native open panel (`core/desktopFiles.ts`) |
| Protect | Open password, AES-256 | MVP | 🟡 | 🟡 | 🟡 | EmbedPDF sets an open password and permissions (e2e: the saved file is encrypted and reopens only with its password, through Warraq's prompt, in both engines). Warraq's core reads R2–R6 (RC4 40/128, AES-128, AES-256) and keeps the protection on what it appends — a text edit or a page change saves encrypted with the file's own key (checked by PDFium; e2e: edit, save, the password is still asked for) |
| Edit PDF | Add a line of text where you click | MVP | ✅ | ✅ | ✅ | shaped, subset and embedded like any replacement, in a chosen face (Amiri, Cairo, Inter) and size; RTL grows leftwards from the point. Not on the undo stack yet |
| Edit PDF | Text edit with reflow (Arabic-correct) | MVP | ✅ | ✅ | ✅ | click a paragraph, edit in place, undo/redo, save. GATE 2 passed on a real Word export and a scan (`docs/gate-2.md`); Acrobat verification still outstanding |
| Edit PDF | Images replace/resize/crop, links, headers/footers, watermarks, Bates, page numbers | MVP/v1 | ⬜ | ⬜ | ⬜ | |
| Scan & OCR | Arabic + English OCR, deskew, cleanup, searchable image PDF | v1 | 🟡 | ✅ | ✅ | tesseract.js 7 in every host (the desktop webview too), models bundled (ara, eng, fas, urd "best int"); an invisible, shaped text layer written by Warraq's core as an incremental update (e2e: 94 % of the Arabic words of a 300 dpi scan, read back after save and reopen). crooked pages are straightened before they are read (e2e: 93 % of a page 8° off true, against 56 % unstraightened); no cleanup yet; desktop recognition not yet watched |
| Export / Create | PDF → Word/Excel/PowerPoint/images/HTML/text; Office/images/HTML → PDF; combine | v1 | 🟡 | 🟡 | 🟡 | PDF → Word (flowing right-to-left paragraphs, text only; valid against the ISO/IEC 29500 schemas, not yet opened in Word), text, Markdown, HTML and PNG page images, from Warraq's own logical-order text (e2e: every format; redactions never leak). Excel, PowerPoint and anything → PDF not yet |
| Prepare Form | Create fields, auto-detect, calculations, safe JS subset | v1 | 🟡 | 🟡 | 🟡 | EmbedPDF creates text fields, checkboxes, radio buttons, drop-downs and list boxes as real AcroForm fields (e2e). Auto-detect and calculations not yet; XFA read-only/limited |
| Redact | Text, area, search-and-redact, metadata scrub, true removal | v1 | ✅ | ✅ | ✅ | EmbedPDF marks text or an area and applies it as true removal (e2e: the text is gone from the saved file, the rest is intact). Find and redact: Warraq's Arabic-aware search (diacritics, alef/taa/yaa/digit forms) plus ready-made patterns — emails, Saudi and international phones in Latin or Arabic-Indic digits, national ID/Iqama, IBAN (mod 97), card numbers (Luhn), Arabic/English/Hijri-month dates — or a person's own linear-time regex; each match listed with page and context, chosen ones become EmbedPDF's own pending marks over their glyph boxes (e2e: an Arabic word, an English word and an email marked, applied, saved; gone for Warraq's reader and from every inflated content stream, literal or hex, and as ActualText; the rest intact). Remove hidden information: a report of metadata/XMP, scripts and actions, attachments, comments, form data (fields flattened into the page), hidden layers, bookmarks, thumbnails, PieceInfo, links, hidden text (invisible, white, off-page), earlier revisions and unreferenced objects; removal writes the file whole (Rust tests grep the bytes and inflated streams for each item; e2e: every marker gone from the saved file, one revision). Limits: text hidden under an image or by a clip path is not detected, nor hidden text inside form XObjects; protected files are refused (the rewrite would lose the password) |
| Compare | Text + visual diff | v1 | ✅ | ✅ | ✅ | the text of two versions — the file's own earlier revisions or another PDF — word by word, Arabic-aware, and how each page looks, drawn and compared with the changes outlined; a report with both (e2e: an earlier revision, another PDF, a diacritics-only change, a protected copy, a drawing only the pictures show) |
| Signatures | PAdES sign (PKCS#12, smart card), verify chain, timestamps, LTV | v1 | ⬜ | ❌ smart card | ⬜ | RustCrypto; smart cards desktop-only |
| Accessibility | Tags, reading order, alt text, checker | v2 | ⬜ | ⬜ | ⬜ | |
| Action Wizard | Batch processing | v2 | ⬜ | ⬜ | ⬜ | |
| Print production | PDF/A & PDF/X conversion + validation, preflight light | v2 | ⬜ | ⬜ | ⬜ | krilla for PDF/A output |
| AI | Summarize, chat, translate, OCR post-correction, smart fill, PII suggestions, table extraction | v1 | 🟡 | 🟡 | 🟡 | summarize, ask, translate with a bring-your-own Anthropic key or a local model (Ollama, LM Studio); nothing sent before Send, the exact text shown first, answers streamed as they are written and citing pages (e2e with both providers faked, streamed and whole); OCR post-correction, smart fill, PII and tables not yet |
| Cloud | OneDrive and Google Drive connectors (independent) | v1 | ⬜ | ⬜ | ⬜ | Phase 5 |
